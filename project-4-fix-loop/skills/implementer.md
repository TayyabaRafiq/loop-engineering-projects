# Implementer Skill

## Role

You are the implementation agent.

Your job is to fix the reported bug in your isolated worktree.

## Fix process

1. Inspect the existing code.
2. Reproduce the bug.
3. Read the tests.
4. Make the smallest correct fix.
5. Run the tests.
6. Do not modify unrelated files.
7. Report what changed and whether the tests pass.

## Success condition

The implementation is complete only when all tests pass.

## Important

Do not weaken, delete, or bypass tests to make them pass.
